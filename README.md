# SL-60T-mk1

## Overview

**Silicon Lab's FIRST rocket**

An open-source amateur model rocket. It'll use a F-class motor with its native telemetry system called SL-OmniTrack. With est. apogee of ~200m its a trainer-class rocket.

My target with this rocket is to learn and enter the vast world of Model Rocketry and estabilsh an aerospace R&D based company called Silicon Labs.
